## ⚠️ IMPORTANT - Before First Run

**Update backend URL in `src/services/api.ts` (line 6):**

### For Emulator:
```typescript
const API_BASE_URL = 'http://10.0.2.2:5000/api';
```

### For Your Phone:
```typescript
const API_BASE_URL = 'http://YOUR_COMPUTER_IP:5000/api';
```

**Find your IP:** Open CMD → `ipconfig` → IPv4 Address

## 🔄 Development Workflow

```bash
# Daily development
npm start              # Start Metro
npm run android        # Run app

# If errors
npm start -- --reset-cache
cd android && ./gradlew clean && cd ..

# Build APK
cd android
./gradlew assembleRelease
```

## 💡 Quick Tips

1. **Backend must be running** on port 5000
2. **Metro must stay open** while developing
3. **Hot reload** auto-updates on file save
