## 🚀 3 Steps to See Your App

### **1. Update Backend URL**
Open: `src/services/api.ts` (line 6)

**For Android Emulator:**
```typescript
const API_BASE_URL = 'http://10.0.2.2:5000/api';
```

**For Your Phone:**
Find your IP: CMD → `ipconfig` → IPv4 Address
```typescript
const API_BASE_URL = 'http://192.168.1.XXX:5000/api';
```

### **2. Start Backend**
```bash
cd "C:\Accuro Deployed\calibrex-accuro\backend"
npm run dev
```

### **3. Run Mobile App**

**Terminal 1:**
```bash
cd "C:\Accuro Deployed\calibrex-accuro\AccuroMobile"
npm start
```

**Terminal 2 (new window):**
```bash
cd "C:\Accuro Deployed\calibrex-accuro\AccuroMobile"
npm run android
```

**App will launch in 2-5 minutes!** ⏱️
